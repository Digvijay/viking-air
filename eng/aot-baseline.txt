# Reviewed Native AOT warning baseline
#
# Every entry here is a trim/AOT warning that Native AOT publication reports and that
# Viking Air cannot fix, because it originates inside a third-party dependency.
#
# This file exists so that the AOT gate can stay green on a KNOWN set while still failing
# on anything new. It is not a suppression list and must never be used to silence a warning
# in code this repository owns. eng/check-aot-warnings.ps1 enforces that structurally: an
# entry whose origin is a first-party namespace is rejected outright, and an entry that no
# longer occurs is reported as stale so the baseline shrinks as upstream improves.
#
# Reviewed 2026-09-28 against Digvijay/viking-air run 36379747859. 22 unique signatures,
# identical on ubuntu-latest and windows-latest.
#
# ---------------------------------------------------------------------------------------
# MemoryPack (14 entries)
#   MemoryPackFormatterProvider builds formatters for closed generic types at runtime via
#   Type.MakeGenericType / MethodInfo.MakeGenericMethod, and TypeFormatter resolves types
#   from a name on the wire via Type.GetType. Those are reflection operations ILC cannot
#   prove. They are inherent to MemoryPack's dynamic formatter lookup, not to how Viking
#   Air calls it. Upstream tracks Native AOT support; there is no consumer-side fix.
#
# Microsoft.Extensions.Caching.Hybrid / System.Text.Json (8 entries)
#   HybridCache's DefaultJsonSerializerFactory falls back to JsonSerializerOptions.Default
#   and inspects candidate types reflectively to decide whether a type is field-only. The
#   reflective path is selected inside the library; supplying a JsonSerializerContext from
#   Viking Air does not remove it from the call graph, so it cannot be cleared here.
#
# Neither dependency can be fixed by this repository. If either is dropped from the AOT
# published path, or ships an AOT-clean release, delete the corresponding entries - the
# checker will report them as stale.
# ---------------------------------------------------------------------------------------
